# 快速上手

## 1. 下载并解压

从 GitHub 仓库的 **Releases → Assets** 下载 `VoxelCutLab-v0.17-windows-x64.zip`，完整解压后双击 `VoxelCutLab.exe`。便携版不需要安装，也不需要管理员权限。

压缩包中的 `VoxelCutCase.exe` 是程序配套的计算进程；DLL、`osgPlugins-3.6.5` 和 `cases` 都是运行所需文件。请保留它们，不要只复制主程序。

## 2. 看一次单步讲解

程序默认打开「单步讲解」，暂停在毛坯初始化。

1. 点击右上方选择一种算法。
2. 点击「下一步」，观察整体视图和右侧局部视图。
3. 点击「播放」自动推进；按空格暂停。
4. 点击进度条回看，或用「下一阶段」跳转。

## 3. 看一次完整加工

点击顶部「完整加工」，再点击「播放」。拖动鼠标旋转模型，滚轮缩放。按 **H** 复位视角，按 **Enter** 跳到最终结果。

## 4. 运行一次性能测试

1. 点击顶部「性能测试」。
2. 选择算法与算例。首次可用原项目或工件 2；球头刀加工有 62378 个刀位，计算规模更大。
3. 首次可将采样间距手动设置为 **0.05 mm**，刷新间隔设为 **1000**。
4. 点击「启动测试」，观察进度与统计。
5. 若选用 SparseOctree 或 Radial Dexel，在完成或停止后点击「表面重建」，观察三角网格；再次点击返回原显示。邻接扩散体素暂不支持重建。

SparseOctree 在普通教学展示中也可点击「重建／展开」查看当前材料的重建结果。

默认间距为 0.005 mm；程序不会自动降低精度。暂停和停止会在算法安全边界生效，初始化或较长计算批次期间可能需要等待。

运行要求和故障排查见 [使用说明](USER_GUIDE.md)。返回 [项目首页](../README.md)。
