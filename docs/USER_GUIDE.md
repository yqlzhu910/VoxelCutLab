# 使用说明

## 运行要求

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10/11 x64 |
| 处理器 | x64，支持 SSE / BMI2 指令 |
| 图形 | OpenGL 3.2 compatibility / GLSL 1.50 |
| 运行库 | 发布包附带所需 MFC、MSVC、OpenMP 与 OSG 运行文件 |
| 字体 | 使用 Windows 中已有的微软雅黑或黑体，包内不附带系统字体 |

内存需求随算法、算例和间距变化。首次测试可从 0.05 或 0.1 mm 开始，再逐步减小间距。更小的间距不是绝对几何误差保证。

## 快捷操作

| 操作 | 快捷键 |
|---|---|
| 播放 / 暂停；测试页启动 / 暂停 / 继续 | 空格 |
| 上一步 / 下一步 | ← / →，或 B / N |
| 下一阶段；完整加工跳到末尾 | Enter |
| 展示回到开头 | R |
| 单步讲解 / 完整加工 / 性能测试 | 1 / 2 / 3 |
| 显示或隐藏局部视图 | F |
| 复位整体视角 | H |
| 剖切 / 方块边线 | C / W |
| 播放加速 / 减速 | + / − |
| 旋转 / 缩放 | 鼠标拖动 / 滚轮 |

播放倍率控制观看速度，与算法计算性能无关。剖切是显示辅助，不是任意精确切平面工具。

## 三种页面

**单步讲解**从真实计算记录中选取代表对象，说明初始化、区域筛选和材料变化。可选 1～15 个教学刀位；每个单刀位独立作用于新毛坯。讲解省略其他对象的重复处理，不是全部事件的逐条回放。

**完整加工**展示教学路径上的连续加工状态。Radial Dexel 的教学展示还包含重建网格。

**性能测试**运行完整输入。三个内置算例分别是原项目四工序（4658 刀位）、工件 2（2502 刀位）、文献参数派生螺旋槽（3221 刀位）。当前版本仅支持内置算例。

## 测试参数

- 间距可选 **0.005 / 0.01 / 0.02 / 0.05 / 0.1 mm**；默认与最小值均为 0.005 mm。
- 体素算法中该值表示体素边长；径向算法中表示轴向和外圆弧采样间距。
- 可每 **1 / 10 / 100 / 1000** 刀位刷新，也可选择「仅结果」。这是刀位间隔，不是帧率。
- 开始后可暂停、继续或停止；重新配置间距前请先重置。
- 刷新间隔会影响计算批次。比较运行结果时，应保持算法、算例、间距、刷新设置和线程条件一致。

## 如何理解统计

总耗时统计初始化、切削、工件几何更新和最终整理；不包含暂停、界面绘制、进程启动和传输等待。刀位/s 使用切削阶段耗时计算。

当前 / 最高内存表示独立计算进程的工作集，单位 MiB。它包含运行库、算法和传输缓存，不包含界面进程和 GPU 显存，因此不能直接等同于算法数据结构的大小。

Radial Dexel 的表面重建不计入切削耗时，但会增加内存。停止处理的是已完成部分，仍可能需要等待最终整理。

## 表面重建与结果边界

Radial Dexel 完成或停止后，「表面重建」生成三角网格，再次点击可返回点显示。其他两种算法的该按钮不可用。

网格是采样近似，不是精确 CAD 曲面。离散刀位留下的加工痕迹可能仍可见。文献参数派生螺旋槽只用于演示，不应作为论文 F4 几何或精度的复现结果。

## 常见问题

**提示缺少 DLL，或找不到算例**  
重新完整解压程序包，并确认两个 EXE、DLL、插件目录和 `cases` 在同一个发布目录。不要直接在 ZIP 内运行。

**窗口空白、文字异常或显示失败**  
核对显卡驱动的 OpenGL 支持，更新显卡厂商驱动；远程桌面或虚拟机的图形支持可能与本地不同。确认系统中有可用中文字体。

**测试长时间没有刷新**  
检查是否选择「仅结果」，以及是否处于初始化、计算批次或最终整理。暂停和停止不会逐指令中断这些阶段。

**内存不足或计算失败**  
重置后增大采样间距，例如改用 0.05 或 0.1 mm。程序保留用户选择，不自动降档。

**下载后出现 Windows 文件来源提示**  
确认下载来源和文件名；可用 Release 同时提供的 `SHA256SUMS.txt` 校验压缩包。遵循所在设备的安全策略。

**如何移除便携版**  
关闭程序后删除其解压目录即可。
